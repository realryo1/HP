# 2027さっぽろ雪まつり 特設サイト — Cursor実装指示書

## 0. 目的

GitHub Pagesで公開する、**非公式の「2027さっぽろ雪まつり」案内用・静的ランディングページ**を制作する。

- 公式サイトそのものを模倣しない
- ページ上部・フッターに `非公式ファンメイドサイト / 情報は公式サイトでご確認ください` を明記する
- 公式ロゴ、公式写真、キャラクター、協賛企業ロゴ、権利物の画像は無断で使わない
- 写真は自作・利用許諾済み・著作権フリー素材のみ。素材がない状態でも成立するよう、CSSの雪・グラデーション・抽象的な雪の結晶で構成する
- 2027年の詳細プログラムや個別雪像名は今後更新予定の情報が多いため、確定情報と未発表情報を混同しない

サイトの狙いは「開催日・3会場・回り方・防寒」を一目で分かるようにし、公式サイトへ誘導すること。

---

## 1. 技術・ファイル要件

ファイル構成は必ず次の3ファイルだけにする。

```text
/
├── index.html
├── style.css
└── script.js
```

### 実装制約

- ビルドツール、Node.js、フレームワーク、外部ライブラリは使わない
- 素の HTML / CSS / JavaScript だけで完結させる
- GitHub Pagesのプロジェクトページ・ユーザーページのどちらでも動く相対パス構成にする
- 画像ファイルに依存しない。背景、アイコン、雪、カードのビジュアルは CSS / 絵文字 / インラインSVGで実装する
- Google Fontsなど外部フォント読み込みは不要。`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "Hiragino Sans", "Noto Sans JP", sans-serif` を使用
- JavaScript無効でも本文とリンクを読めるようにする
- レスポンシブ対応はモバイルファースト。375px幅から破綻しないこと
- キーボード操作、フォーカス表示、十分な色コントラスト、`prefers-reduced-motion` に配慮する
- `target="_blank"` の外部リンクには `rel="noopener noreferrer"` を付ける

## 4. デザイン仕様



### コンセプト

キーワードは `midnight blue / ice blue / frosted glass / snow particles / city lights`。

観光パンフレット風ではなく、テック系イベントLPに近いモダンな夜の冬景色にする。雪の白と氷の青をアクセントにし、札幌の夜・ライトアップの期待感を出す。

### カラートークン

```css
:root {
  --bg: #07111f;
  --bg-deep: #030812;
  --surface: rgba(255, 255, 255, 0.07);
  --surface-strong: rgba(255, 255, 255, 0.12);
  --text: #f6fbff;
  --muted: #aabed2;
  --ice: #8ee7ff;
  --ice-strong: #42caff;
  --violet: #9486ff;
  --line: rgba(184, 226, 255, 0.18);
  --shadow: 0 20px 60px rgba(0, 0, 0, 0.35);
}
```



### レイアウト

- 最大コンテンツ幅: `1160px`
- 横余白: desktop 24px〜32px / mobile 18px
- セクション上下余白: desktop 112px / mobile 72px
- 角丸: 20px〜28px
- カード: ガラス風、薄いボーダー、控えめな内側ハイライト
- 大見出し: clampでサイズ可変。モバイルでも改行が美しいこと
- `scroll-behavior: smooth` を指定。ただし reduced motion時は無効化



### アニメーション

軽量で控えめにする。

- 雪粒: CSS animationでゆっくり落下・横揺れ。粒子要素は最大45個
- セクション要素: IntersectionObserverで `.is-visible` を付け、opacity + 12px程度のtranslateYでフェードアップ
- 会場カード: hover/focus-withinで `translateY(-6px)` とボーダー発光
- 大通マップ: 選択丁目の切替で詳細パネルを短くクロスフェード
- CTA: hoverで少し明るく、1〜2px上に移動
- 点滅、強いパララックス、連続的な大きいtransformは使わない
- `prefers-reduced-motion: reduce` では雪粒子、スクロールアニメーション、トランジションを無効化またはほぼゼロにする

## 5. JavaScript仕様

`script.js` で以下を実装する。

1. 雪粒生成
  - `#snow-layer` にランダムなspanを最大40個追加
  - CSSカスタムプロパティでサイズ、位置、速度、遅延、横揺れ量を個別設定
  - reduced motion時は生成しない
2. スクロール連動ヘッダー
  - 20px以上スクロールしたら `.is-scrolled` をheaderに付与
3. スクロール出現
  - `.reveal` をIntersectionObserverで監視し、表示時に `.is-visible`
  - IntersectionObserver非対応なら全要素を表示
4. 大通丁目切替
  - `[data-block]` を持つボタンをクリックまたはEnter/Spaceで選択
  - `aria-pressed`、選択状態クラス、詳細パネルの丁目・内容・説明を更新
  - データはJS内のオブジェクトにまとめる
  - 11件のデータ内容は「2. 事実として掲載する情報」にある丁目構成だけを使用
5. トップへ戻るボタン
  - スクロール量に応じて表示
  - クリックでトップへスムーススクロール。ただしreduced motionなら即時移動
6. 年号
  - フッターの年号要素に現在年を表示してよい。ただしイベント日付は固定の2027年であること

## 6. アクセシビリティ・SEO



### アクセシビリティ

- `<header>`, `<main>`, `<section>`, `<nav>`, `<footer>` を適切に使用
- ページ先頭に「本文へスキップ」リンクを置く
- アイコンだけの操作要素には `aria-label`
- 雪粒レイヤーは `aria-hidden="true"`
- 装飾SVGは `aria-hidden="true" focusable="false"`
- フォーカスリングは消さず、`outline: 2px solid var(--ice)` 程度を設ける
- 地図風丁目UIは実際にはボタンで実装し、タップ領域を44px以上確保



### SEO・メタ

`index.html` のheadに以下を入れる。

```html
<meta charset="UTF-8" />
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
<meta name="description" content="2027さっぽろ雪まつりの開催日、3会場、回り方、防寒のポイントをまとめた非公式ガイドです。" />
<meta name="theme-color" content="#07111f" />
<title>2027さっぽろ雪まつり｜非公式ガイド</title>
```

OGP画像は3ファイル縛りのため設定しない。存在しない画像URLを指定しない。
